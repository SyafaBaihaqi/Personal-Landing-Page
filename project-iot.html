Electronics & IoT Projects

A collection of small IoT projects I am working on with ESP32 boards and sensors — for example room temperature and humidity monitoring. Each project has its own requirements, build, and progress documentation on my project website.

Overview

I enjoy combining electronics and software. My IoT projects start from a physical problem — like monitoring a room's temperature and humidity — and solve it with a small pipeline: a sensor on an ESP32 board, a REST API to receive the data, a database to store it, and a web dashboard to read it.

These projects follow the same structure as the ILMS project: sensor → ESP32 → REST API → database → dashboard, with honest documentation at every step. Not every project makes it to a finished version; some stay as experiments or designs.

Status: several projects are in the design or experiment stage. Full details, documentation, and progress of each project live on my project website project.saiasyap.my.id.

The Problem

  • Monitoring conditions (for example temperature in a room) is still done by hand.
  • History is hard to trace and often incomplete.
  • No way to spot trends over time.
  • No central dashboard; records are scattered.
  • No warning when a condition passes a safe threshold.

Key Features

  • End-to-end flow: sensor → ESP32 → REST API → database → dashboard.
  • ESP32 boards with various sensors (DHT22/AM2302 temperature & humidity and more).
  • REST API with device-token authentication for each sensor node.
  • Web dashboards: latest values, history, charts, and device status.
  • Threshold logic with NORMAL / WARNING / CRITICAL status and notifications.
  • Installable web PWA dashboard with offline shell.
  • Every project documented with its own page on project.saiasyap.my.id.

Tech Stack & Architecture

Technology used in the electronics/IoT projects
Layer Technology
Hardware ESP32 DevKit, sensors (DHT22/AM2302 and more)
Firmware Arduino/C++ (sensor libraries, WiFi, HTTP)
Backend REST API built with Node.js/Express (or equivalent)
Database SQLite / MySQL / PostgreSQL, normalized schema
Frontend Web PWA dashboard (mobile-first, time-series chart)
