Featured Project

IoT Lab Management System (ILMS)

A web-based IoT laboratory management system covering component inventory, a structured loan workflow, stock audit, ESP32 devices, and sensor monitoring. Built as a modular portfolio case study for lab management.

  • Authentication + RBAC (Admin / Dosen / Mahasiswa / User)
  • Loan workflow, stock history, and QR code inventory labels
  • Reports export to CSV, Excel, and multi-page PDF
  • ESP32 integration: registration, heartbeat, sensor readings
  • React PWA frontend with Express + Prisma backend, PostgreSQL
