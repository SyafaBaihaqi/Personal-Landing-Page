Featured Project

IoT Lab Management System

ILMS is a web-based system for managing an IoT laboratory: component inventory, a structured loan workflow, ESP32 devices, and real-time sensor monitoring — replacing manual records with a centralized, auditable platform.

Open Live Demo View Source on GitHub

Overview

ILMS (IoT Lab Management System) is a portfolio case study built around real laboratory problems. It centralizes inventory and stock data, tracks who borrows what, automates loan approval and returns, and connects to ESP32 sensor nodes for monitoring.

The system is organized into four building stages: MVP, Portfolio+, Basic IoT, and Advanced IoT — keeping the codebase modular and easy to extend.

The Problem

  • Component stock was still recorded manually.
  • Hard to track who borrowed which component.
  • Stock shortages went undetected.
  • Overdue loans were not monitored.
  • Producing reports for administration and audits was slow.

Key Features

  • Authentication and RBAC (Admin, Dosen, Mahasiswa, User) with JWT + refresh tokens.
  • Component, category, and real-time stock management with change history.
  • Structured loan flow: request → approve/reject → return, wrapped in database transactions.
  • Role-based dashboards and in-app notifications.
  • Reports (inventory, loans, damage, IoT) exported to CSV, Excel, and multi-page PDF.
  • Loan letter (PDF) per transaction for Admin/Dosen.
  • QR code inventory labels per component, ready to print, with quick QR scanning.
  • ESP32 integration: device registration, heartbeat, and sensor data via a dedicated API key.
  • Customer service ticketing with status, priority, reply threads, and staff notifications.
  • Installable PWA with offline shell, full audit log, and overdue loan flagging.

Tech Stack & Architecture

Technology stack used in ILMS
Layer Technology
Frontend React 18, Vite, TypeScript, Tailwind CSS, PWA (Workbox)
Backend Node.js, Express, TypeScript, Zod, JWT
Database PostgreSQL, Prisma ORM
IoT ESP32, ArduinoJson, DHT22, HC-SR04 
Client (PWA) --HTTPS--> API (Express/TS) --> Business Logic (Services) --> ORM (Prisma) --> PostgreSQL
ESP32 + Sensor --HTTP--> REST API (API Key) --> Business Logic --> Database
